## รายละเอียดข้อพบและหลักฐานการแก้ไข

### BLOCKER (แก้ไขครบ 2/2)
1. **BLOCKER-1 — Python ↔ Dart Rounding Parity (`39.95 → 39.9 vs 40.0` ข้าม 141 level boundaries):**
   - **สาเหตุ:** `backend/pipeline.py` ใช้ `Decimal(str(100.0 * raw))` โดยไม่ชดเชย IEEE-754 epsilon ขณะที่ Dart ใช้ `floor(value * 10 + 0.5 + 1e-9) / 10`
   - **การแก้ไข:** ปรับ `_round_half_up` ใน `backend/pipeline.py` ให้ใช้ `math.floor(value * scale + 0.5 + 1e-9) / scale` ตรงกับ Dart 100% และเพิ่ม `TV2-10` (`39.95 → 40.0`, Level 3) ในทั้ง `backend/tests/test_pipeline.py` และ `mobile/app/test/alert_engine_test.dart`
2. **BLOCKER-2 — Life-Safety UI: แสดงแบนเนอร์สีเขียว "สถานการณ์ดีขึ้นแล้ว" ระหว่างน้ำท่วมระดับ 4/5:**
   - **สาเหตุ:** `AlertProvider.activeAlerts` ส่ง `previous: _alerts` เข้า `evaluate()` ทำให้ Cooldown 30 นาทีซ่อนสถานีที่กำลังวิกฤต
   - **การแก้ไข:** ปรับ `AlertProvider.activeAlerts` ให้ส่ง `previous: const <AlertItem>[]` และเพิ่ม regression assertion `expect(provider.activeAlerts, isNotEmpty)` ใน `mobile/app/test/app_smoke_test.dart`

### HIGH (แก้ไขครบ 3/3)
3. **HIGH-1 — `AlertSettings.copyWith` ไม่สามารถล้าง `selectedTumbonTh` เป็น `null` ได้เมื่อเปลี่ยนอำเภอ:**
   - **การแก้ไข:** เพิ่ม `bool clearAmphoe = false, bool clearTumbon = false` ใน `AlertSettings.copyWith`, ผูกใน `SettingsScreen`, และเพิ่ม unit test ยืนยันใน `alert_engine_test.dart`
4. **HIGH-2 — DOM XSS ใน `mobile/preview/index.html` (`onclick` inline string + unescaped `h.time` + ขาด `rel="noopener noreferrer"`):**
   - **การแก้ไข:** เปลี่ยนไปใช้ `data-amphoe="${esc(...)}"` ร่วมกับ `this.dataset.amphoe`, ครอบ `h.time`/`h.mm` ด้วย `esc()`, และเพิ่ม `rel="noopener noreferrer"` บนลิงก์ภายนอก
5. **HIGH-3 — ขอบเขต Flutter Phase 1.5 vs 5-Source Pipeline CDN (Phase 2):**
   - **การแก้ไข:** ชี้แจงใน `SettingsScreen` อย่างโปร่งใสว่า Phase 1.5 บนแอป Flutter ดึงระดับน้ำสด 14 สถานีจาก ThaiWater พร้อม Formula v2 engine ในเครื่อง ส่วนข้อมูล 5 แหล่งเต็มรูปแบบ (87 ฝน + เขื่อนบางลาง + Open-Meteo + GloFAS) รันจริงบน Pipeline + iOS Preview และจะเชื่อมผ่าน Supabase CDN ใน Phase 2

### MEDIUM & LOW (แก้ไขแล้ว)
- **MEDIUM-1:** ตัด `age_minutes` และ `latency_ms` ออกจาก canonical payload ของ `content_hash()` เพื่อให้ hash คงที่ 100% เมื่อข้อมูลต้นทางไม่เปลี่ยน (เพิ่ม test ข้ามเวลา `15:30` vs `15:35` ICT)
- **MEDIUM-2:** แยก flag `unusable_sensor: true` รายสถานีกรณีเซนเซอร์ตัวเดียวส่ง `null + stale` ไม่ให้ล้มข้อมูลทั้งจังหวัด (ยัง fail-closed เมื่อทุกสถานี stale/ใช้งานไม่ได้)
- **MEDIUM-3:** เพิ่มปุ่มโทร **191 (ตำรวจ)** ใน `SosScreen` และยกเลิก `.slice(0, 6)` ใน `mobile/preview/index.html` เพื่อแสดงครบทั้ง 9 หน่วยงานยืนยันแล้ว
- **MEDIUM-4:** ปรับคำเตือนใน `shelters.yaml` และป้ายใน `mobile/preview/index.html` เป็น **"ชื่อทางการ (พิกัดโดยประมาณ)"** เพื่อความโปร่งใสสูงสุด
- **MEDIUM-5:** ใช้ `None`-safe check + กรองค่าลบใน `fetch_banglang_dam()`, ส่ง `now_ict` เข้า `fetch_open_meteo_weather()`, เพิ่ม guard future timestamp (`age_min < -15`), ปรับ `Station.bankLevel` ข้ามค่า `<= 0` ให้ตรงกับ Python, และแก้ชื่อ key ในสเปกเป็น `thaiwater_rain_24h` + `60 นาที`
- **LOW-1 & LOW-3:** ล้าง `_position`/`_phoneController` ในหน่วยความจำของ `SosScreen` ทันทีเมื่อผู้ใช้กด "ลบข้อมูลของฉันทั้งหมด (PDPA)", แก้คำผิด `'น้ำท่วมบ้าน/ชุมชน'` ใน `sos_request.dart`, และเพิ่ม SnackBar กรณีโทรไม่สำเร็จใน `shelters_screen.dart`
