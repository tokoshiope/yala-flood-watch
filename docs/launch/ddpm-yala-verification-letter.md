# แบบฟอร์มขอความอนุเคราะห์ยืนยันข้อมูลศูนย์พักพิงและเบอร์ติดต่อฉุกเฉิน

> ใช้ส่งทางหนังสือ/อีเมล หรือส่งข้อความทาง **LINE `@1784DDPM`** / **LINE `@yalacity`** / โทรประสาน **ปภ.ยะลา `073-203559`** เพื่อยืนยันข้อมูลจริงก่อนปลดป้าย `"อ้างอิงจากข้อมูลเดิม รอยืนยัน"` ในแอป **แจ้งเตือนน้ำท่วมยะลา**

## ข้อความพร้อมส่ง (สำหรับ LINE / อีเมล / ประสานงานเจ้าหน้าที่)

> เรื่อง: ขอความอนุเคราะห์ยืนยันรายชื่อ พิกัดศูนย์พักพิงชั่วคราว และหมายเลขโทรศัพท์ประสานงานภัยพิบัติระดับอำเภอ จังหวัดยะลา
>
> เรียน หัวหน้าสำนักงานป้องกันและบรรเทาสาธารณภัยจังหวัดยะลา / เจ้าหน้าที่ฝ่ายป้องกันและบรรเทาสาธารณภัย
>
> ด้วยข้าพเจ้าได้พัฒนาแอปพลิเคชันเพื่อสาธารณประโยชน์ **"แจ้งเตือนน้ำท่วมยะลา (Yala Flood Watch)"** (ให้บริการฟรี 100% ไม่มีโฆษณา และไม่แสวงหาผลกำไร) เพื่อช่วยแจ้งเตือนภัยน้ำท่วมล่วงหน้าแก่ประชาชนในพื้นที่ทั้ง 8 อำเภอของจังหวัดยะลา โดยเชื่อมโยงข้อมูลระดับน้ำ ฝน และเขื่อนบางลางจากระบบคลังข้อมูลน้ำแห่งชาติ (สสน.)
>
> เพื่อให้ข้อมูลศูนย์พักพิงและช่องทางขอความช่วยเหลือในแอปมีความถูกต้องแม่นยำตามข้อเท็จจริงของทางราชการ จึงขอความอนุเคราะห์ยืนยันข้อมูล 2 รายการดังนี้:
> 1. รายชื่อและพิกัด GPS ที่ถูกต้องของศูนย์พักพิงชั่วคราวประจำแต่ละอำเภอ (ทั้ง 8 อำเภอ) ที่เตรียมรองรับผู้ประสบภัยในปีปัจจุบัน
> 2. หมายเลขโทรศัพท์ติดต่อตรงของศูนย์บัญชาการเหตุการณ์ประจำอำเภอ / อปท. ทั้ง 7 อำเภอรอบนอก (รามัน, ยะหา, กรงปินัง, บันนังสตา, เบตง, ธารโต, กาบัง)
>
> ทั้งนี้ ในแอปพลิเคชันได้ระบุคำชี้แจงอย่างชัดเจนว่าเป็นเครื่องมือเฝ้าระวังอิสระ ไม่ใช่ช่องทางกู้ภัยหลัก และแนะนำให้ประชาชนโทรแจ้งเหตุฉุกเฉินที่ 1784, 073-203559 หรือ 1669 โดยตรง
